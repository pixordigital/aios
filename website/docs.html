Documentação da API

Referência da API
do AIOS

Implante, gerencie e governe agentes de IA via API REST. Abaixo, os endpoints principais. Para uma referência interativa completa, acesse o Swagger UI.

01 / Autenticação

POST/api/auth/register

Cria uma nova conta de usuário. Retorna um token de acesso.

{ "email": "voce@exemplo.com", "password": "senha-forte" }

POST/api/auth/login

Autentica com e-mail e senha. Retorna um token para usar nas requisições autenticadas.

GET/api/auth/me

Retorna o usuário e a organização autenticados.

02 / Agentes

GET/api/agents

Lista todos os agentes da sua organização.

POST/api/agents

Cria um novo agente. Tipos disponíveis: sdrclosersupportorchestratorcustom

{ "name": "Bot de Suporte", "agent_type": "support", "model": "gpt-4o", "system_prompt": "Você ajuda clientes..." }

PUT/api/agents/{id}

Atualiza um agente existente. Você pode trocar o modelo, o prompt ou as ferramentas sem reimplantar.

03 / Canais

GET/api/channels

Lista os canais conectados da organização.

POST/api/channels

Conecta um novo canal. Tipos: webwhatsappevolutionslacktelegramdiscordemail

04 / Conversas

GET/api/conversations

Lista as conversas com histórico, mensagens e agente responsável.

POST/api/conversations/{id}/send

Envia uma mensagem em nome do agente dentro de uma conversa.

{ "message": "Olá! Como posso ajudar?" }
05 / Equipes

POST/api/teams

Cria uma equipe com estratégia de roteamento: supervisorround_robinbroadcastsemantic

{ "name": "Equipe de Vendas", "routing_strategy": "round_robin", "orchestrator_agent_id": "...", "agent_ids": ["...", "..."] }

GET/api/teams

Lista as equipes da organização com compatibilidade e conflitos de ferramentas.

06 / Cobrança

GET/api/billing

Retorna o plano atual, o uso do período e o histórico de cobranças.

POST/api/billing/checkout

Cria uma sessão de checkout do Stripe para fazer upgrade do plano.

07 / Primeiros passos

1. Crie um agente

Escolha um tipo (SDR, suporte, closer, etc.) e defina o modelo e o prompt do sistema.

2. Conecte um canal

Ligue WhatsApp, e-mail, Slack ou o chat web ao agente para começar a receber mensagens.

3. Implante

Ative o agente e acompanhe a telemetria em tempo real: mensagens, custo por requisição e taxa de erro.
