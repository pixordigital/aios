03 / Suíte de Receita & Governança

AIOS + ARVO:
A inteligência audita, o ledger imutável registra

Uma arquitetura completa para Revenue Operations e Governança Financeira. O AIOS roda os agentes e audita o pipeline; o ARVO mantém o ledger financeiro com idempotência rigorosa.

⚡

AIOS — Motor de Decisão & Deal Desk

• 5 Agentes de Governança monitorando negociações e CRM.
• Control Center (/dashboard/control-center) com fila HITL.
• Disparo de eventos autenticados via HMAC-SHA256 para o ARVO.
• Retentativas automáticas, controle de nonces e proteção anti-replay.

📖

ARVO — Ledger Financeiro & Evidências

• Ledger financeiro imutável e idempotente (cálculos em Decimal, sem float).
• Registro auditável de cada aprovação e execução financeira.
• EvidencePack anexado a cada transação com assinatura digital.
• Zero tolerância a duplicações ou desvios de saldo.

🔄

Fluxo de Integração — Outbox + Eventos Assíncronos

HMAC-SHA256
1️⃣ ARVO detecta risco

audit_job roda → calcula exposure → cria Finding + business_trace_id → publica commitment.at_risk no outbox (HMAC + Idempotency-Key)

2️⃣ AIOS consome + executa

Worker lê outbox → POST /events (dedup) → enfileira process_commitment_at_risk → roda agente (AutonomousAgent/AgentRuntime) → publica agent.action.completed no outbox

3️⃣ ARVO registra evidência

Worker lê outbox → POST /events → _handle_agent_action_completed → cria FindingEvidence + provenance.business_trace_id

Outbox transacional SQLite/Postgres tabela integration_outbox com retry (5x) + cron 30s. Sobrevive a restart. Idempotência integration_nonces (600s) + integration_events (24h TTL) — dedup de retries por 24h.
04 / Base de Conhecimento

Seus PDFs viram memória dos agentes

Menu Base Conhecimento (Arquivos): a equipe faz upload de PDF com dados/contexto do negócio — tabela de preços, FAQ, políticas, catálogo — e todos os agentes consultam via RAG (hybrid_search).

📄

1. Upload PDF

Arraste PDF/TXT/MD/CSV em /dashboard/files. Descrição vira source no RAG. `pypdf` extrai texto, `chunk 800 chars` (até 30 chunks).

🧠

2. Indexa RAG

Cada chunk vira Memory long_term com embedding + artifact_id. Busca hybrid_search (vetor + BM25) com score.

🤖

3. Agentes consultam

SDR/Closer/Suporte/Analyst usam hybrid_search e read_file no RAG. Ex: “qual política de troca?” → resposta com fonte do PDF.

PDF → RAG automático Teste no /dashboard/files: busque “política de troca” após upload. Agentes já usam sem config extra. Abrir Base Conhecimento →
