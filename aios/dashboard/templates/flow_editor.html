Como usar

Paleta → arraste ou clique para criar nó. Conecte: arraste do ponto direito → ponto esquerdo, ou Shift+clique origem → destino. Clique no nó para editar. Salvar persiste posições.

🎯

Passo 1: Arraste da paleta

Segure e arraste qualquer ferramenta (ex: sql_query) da paleta à esquerda para o canvas.

👈 Arraste → 📋
🔗

Passo 2: Conecte handles

Arraste do handle de um nó para o handle de outro. Isso cria depends_on.

nó A —●→ nó B (B depende de A)
💾

Passo 3: Salve

Clique Salvar no topo. O fluxo fica pronto para usar em automações.
